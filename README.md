## I make long-lived Angular applications fast, maintainable and upgradable again.

I work on migrations from Module Federation to Native Federation, on zoneless change detection and Signals, and on the monorepo and upgrade structure around them. Based in Dresden, working with Angular since the beta in 2016.

### Native Federation

I am an Industry Advisor on the [Native Federation team](https://native-federation.com/team/) and maintain its official DevTools.

- [native-federation/devtools](https://github.com/native-federation/devtools): a browser extension that shows which dependencies were shared, isolated or skipped. Available in the [Chrome Web Store](https://chromewebstore.google.com/detail/native-federation-devtool/knbodlnbljndbcbalndkflbhbegdghej) and at [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/native-federation-devtools/).
- Talk: [Seeing the Negotiation: DevTools for Native Federation](https://www.youtube.com/live/bG_eZM02Vfw?t=2483), online meetup "Federation v4 for Angular", August 2026.

### Demos

- [Frankenstein Meeting Room](https://lutzleonhardt.de/frankenstein-meeting-room/): one Angular host with React and Svelte remotes. [Code](https://github.com/lutzleonhardt/FrankensteinMeetingRoom)
- [Conference Finder](https://lutzleonhardt.de/conference-finder/): an LLM composes the UI with A2UI, and Native Federation remotes deliver the components. [Code](https://github.com/lutzleonhardt/native-federation-a2ui)
- [Keppt](https://getkeppt.com): my own app on Angular 22, zoneless. [Code](https://github.com/lutzleonhardt/keppt-app)

The two federation demos are listed on the [Native Federation resources page](https://native-federation.com/resources).
